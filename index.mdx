SpoofSense tells you whether a face in an image is a **real, live person** — not a printed photo, a screen replay, a mask, or an AI-generated deepfake. You send an image (or let our SDKs capture one), we return a decision.

## How a decision works

Every check returns a calibrated `genuine_score` between 0 and 1 and applies:

```text
decision = genuine_score > threshold      (default threshold: 0.5)
```

The score is calibrated so the decision boundary sits at 0.5 across model updates — a threshold you tune today keeps meaning the same thing after we retrain. See [Thresholds & scores](/guides/thresholds).

## Base URL

```text
https://api.spoofsense.ai
```

All endpoints are served over HTTPS. Errors always use one envelope: `{"error": {"code", "message"}}` — see [Errors](/guides/errors).
